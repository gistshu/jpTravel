以下為基礎需求


1. 計畫做一個日本百名城的旅遊紀錄網站
1.1 可以看各城堡位置，類似google map, 城堡簡介
1.2 可讓人上傳旅遊紀錄, 文字, 照片(要自動縮圖壓縮), 不要像FB一樣久了就被洗掉了
1.3 可以開放讓大家搜尋，如某個城，就可以看到所有人的旅遊紀錄
1.4 地圖上可以顯示熱點，某個城很多人發文，代表很受歡迎
1.5 使用google 帳號認證
1.6 個人號稱，一級距加上足輕，侍大將，部將，家老，宿老，小大名，大大名，霸主，天下人等等稱號
1.7 百名城是否有石紀錄，可以作為稱號基礎

2. 手帳優化
2.1 發的文可以手帳化，美美可愛的手帳風格
2.2 手帳版型範本，圖片可以自動化去背，旋轉，不一定要
